# PisunClient 0.7.0

Android Studio source scaffold for Minecraft Pocket Edition 1.1.5 (ARMv7), with an experimental in-process loader and AutoSprint native hook.

## Status
Source integration only. APK build and device runtime testing have not been completed. AutoSprint is experimental and unverified.

## External inputs
Minecraft PE binaries, Variable DEX/classes, third-party native libraries, and compile-only stubs are intentionally excluded. Supply these only if you have the legal right to use them. See STATUS_RU.md and СБОРКА.txt.

Target ABI: armeabi-v7a. Android Gradle Plugin: 8.7.3. CMake: 3.22.1.
